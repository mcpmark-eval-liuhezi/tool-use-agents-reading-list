# tool-use-agents-reading-list

Reading-group paper tracker for **tool use in LLM agents** — agents that select, call, and combine external tools/functions (function calling, tool learning, tool selection and retrieval, multi-step tool invocation).

## How this works

- The paper list lives in GitHub issues rather than a spreadsheet.
- **Parent issue #1: "Tool-Use Agents Reading List"** is the master tracker.
- Each paper gets its own child issue, titled `arXiv ID — paper title`, attached under the parent as a sub-issue. Each child issue carries a 2–3 sentence read summary in its comments.
- Papers that turn out to be out of scope (not tool-use agents) are unlinked from the parent but kept as standalone issues; drops are noted on the parent issue.

## Scope

In: LLM agents that call tools/APIs/functions; tool learning, selection, retrieval; benchmarks and training methods for tool use.

Out: general conversational-search UX, human-subjects trust studies, non-agent work.
